# Liakia PR Deck

This folder contains the PowerPoint deck used to present Liakia as an AI-assisted embedded firmware delivery workflow.

## Files

- `liakia-pr-deck-20260608.pptx`: 48-slide PR presentation deck with speaker notes and generated visual assets.

## Scope

The deck explains Liakia from a presentation and review perspective:

- why embedded delivery needs an evidence-backed workflow;
- how build, flash, test, diagnosis, evidence, and handoff connect;
- how real bench and remote HIL evidence support trust;
- how human-in-the-loop AI diagnosis should be bounded;
- how teams can evaluate adoption and future PR updates.

The web pages in `docs/promo-demo/` remain the primary browser-facing demo. This deck is intended for spoken walkthroughs, stakeholder reviews, and PR/storytelling discussions.
